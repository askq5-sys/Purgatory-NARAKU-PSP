# Purgatory -NARAKU- PSP 1.7.13 — Cleanup Update

This update fixes outdated English text, speeds up gray-tinted scenes and
removes about 200 MB of files the game never used. It has been tested in
PPSSPP; real PSP testing is still pending, and reports are welcome.

## Changes

- Fixed outdated English text in a few scenes: the green key is no longer
  called an iron key, the Cleaver and Axe names are highlighted in the
  choice, and some lines no longer break in the middle of a sentence.
  The Russian translation covers every updated line.
- The Map055 levers play the same sounds as in the PC version.
- Scenes with a gray screen tint (for example Map009 and Map104) take less
  time per frame on a PSP.
- The `assets` folder is about 200 MB smaller: pre-rendered dialog pages,
  the old hand-made opening and other leftovers from early versions were
  removed. The game no longer loads two unused textures at startup.
- Unused code was removed.

For developers: optional swizzled textures (`-DNARAKU_SWIZZLE_TEXTURES=ON`),
an on-screen frame-time counter (`-DNARAKU_PERF_HUD=ON`), a repaired test
suite, `tools/refresh_vm_text.py` and `tools/runtime_assets.py`.

## Installation

Copy the `NARAKU` folder from the archive to `PSP/GAME/` on the memory stick
(or the PPSSPP `PSP/GAME` folder). The folder name must stay `NARAKU`.
A PSP needs custom firmware to run homebrew.

When updating from an older version, delete the old `assets` folder and
`EBOOT.PBP`, then copy the new ones. Saves (`save01.bin` …) and `config.bin`
are next to `EBOOT.PBP` and are kept.
