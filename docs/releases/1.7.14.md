# Purgatory -NARAKU- PSP 1.7.14 — Smoother Dialogue Update

This update removes the short hitches in dialogue scenes, makes the audio
files much smaller without changing how they sound, and speeds up
gray-tinted scenes again. It has been played through the first 30 maps in
PPSSPP; real PSP testing is still pending, and reports are welcome.

## Changes

- Dialogue no longer stutters when a new line or portrait appears:
  recently shown pictures stay in memory, the next portraits are loaded in
  the background while a line is on screen, and message text is built
  several times faster. The text looks exactly the same as before.
- Music and sounds use a new lossless format: the audio files are about
  four times smaller, and they sound the same as before.
- Scenes with a gray screen tint are faster again; the scripted worm
  attack in one of these scenes no longer drops to 30 FPS.
- The save and load menu reads the save slots once when it opens, so
  moving between slots no longer reads the memory stick.

For developers: the frame-time counter (`-DNARAKU_PERF_HUD=ON`) now shows
the map number, heap use, music read time and gaps, picture cache hits
and message text time, and also measures menu frames. `tools/build_deploy.sh`
passes every build option explicitly; `tools/pack_audio.py` converts audio
to the new `.nau` format.

## Installation

Copy the `NARAKU` folder from the archive to `PSP/GAME/` on the memory stick
(or the PPSSPP `PSP/GAME` folder). The folder name must stay `NARAKU`.
A PSP needs custom firmware to run homebrew.

When updating from an older version, delete the old `assets` folder and
`EBOOT.PBP`, then copy the new ones. Saves (`save01.bin` …) and `config.bin`
are next to `EBOOT.PBP` and are kept.
