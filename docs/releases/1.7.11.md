# Purgatory -NARAKU- PSP 1.7.11 — Test Update

This update targets real PSP hardware. Earlier builds started only in
emulators: the EBOOT linked PSP kernel libraries, which PPSSPP accepts but
console firmware does not, so a real PSP showed a black screen before the
game started. 1.7.11 is the first build that should start on a PSP with
custom firmware. It has been tested in PPSSPP; real PSP testing is still
pending, and reports are welcome.

## Changes

- Fixed the black screen on real PSP hardware. The EBOOT no longer imports
  kernel libraries (`SysclibForKernel`, `ThreadManForKernel` and others);
  standard library and thread functions now come from the user-mode SDK
  libraries.
- Fixed Enri's head looking transparent when walking past dark doorways.
  The lower row of the doorway shading is now drawn below characters on
  maps 004, 008, 033, 034, 040 and 069. Walking into a doorway still
  darkens the character as in the original.
- Fixed a loop in transfer handling that read past the end of an array.
- Restored the XMB icon, background and music in the EBOOT.

## Installation

Copy the `NARAKU` folder from the archive to `PSP/GAME/` on the memory stick
(or the PPSSPP `PSP/GAME` folder). The folder name must stay `NARAKU`.
A PSP needs custom firmware to run homebrew.

When updating, replace `EBOOT.PBP` and `assets`. Saves (`save01.bin` …)
and `config.bin` are kept. Restart the game and load an in-game save;
old emulator savestates may not match the new executable.

## Bug reports
