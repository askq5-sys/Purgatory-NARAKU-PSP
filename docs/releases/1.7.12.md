# Purgatory -NARAKU- PSP 1.7.12 — Performance Update

This update removes work that slowed the game down on real PSP hardware.
Gameplay and graphics are unchanged. It has been tested in PPSSPP; real PSP
testing is still pending, and reports are welcome.

## Changes

- Removed a debug log left in release builds. Scenes on Map012 wrote a line
  to `assets/scene_trace.log` on the memory stick for every script command,
  which stalls a real PSP and made the file grow without limit. The old
  `scene_trace.log` can be deleted.
- The game now runs the PSP CPU at 333 MHz instead of the default 222 MHz,
  leaving headroom for streamed music and compressed textures.
- Maps are drawn by walking only the tiles around the screen instead of
  every tile of the map, which saves time on large maps.

## Installation

Copy the `NARAKU` folder from the archive to `PSP/GAME/` on the memory stick
(or the PPSSPP `PSP/GAME` folder). The folder name must stay `NARAKU`.
A PSP needs custom firmware to run homebrew.

When updating from 1.7.11, replace `EBOOT.PBP`; the `assets` folder is
unchanged. Saves (`save01.bin` …) and `config.bin` are kept.

## Bug reports

If the game freezes, slows down or shows a black screen on a real PSP,
please report it with the PSP model, firmware and what appears on screen:
